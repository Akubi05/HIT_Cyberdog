# 如何在仿真环境中运行main.py控制狗运动
**所有终端都需要先激活ROS，方法如下：**

```
source /opt/ros/galactic/setup.bash
source install/setup.bash
```

1. 按照官方文档配置环境直到进入容器，成功启动sim。参考 `HIT_Cyberdog/document/26年文档/cyberdog_race说明文档.md`，注意一定要进入容器运行代码。

看到赛道即表示成功。

2. 确保已激活ROS环境，然后运行 `python3 main.py`。

首次运行会因缺少Python包而报错，使用 `pip3` 安装缺少的包即可，直到Python文件无语法错误能正常运行。

此时狗就会开始行走。

# 附录：状态机测试工作范式

## 快速测试指定状态

修改文件开头第41行：
```python
state_id = 3  # 改为想要测试的状态编号
```

## 状态编号速查

| 状态 | 功能 | 检测函数 |
|------|------|----------|
| 0 | 黄色线检测 | `_detect_0()` |
| 3 | 红色柱检测 | `_detect_3()` |
| 4~53 | 各阶段任务 | `_detect_xxx()` |
| 1,2,7,11,17,31,44,48,53 | 调试显示 | `_show()` |

## 常用操作

| 操作 | 方法 |
|------|------|
| 跳过前面状态 | 直接修改 `state_id = 目标状态` |
| 循环测试某状态 | 状态切换处改回 `state_id = 当前状态` |
| 添加新状态 | 在 `image_callback` 注册 `elif current_state == X` |
| 查看调试图像 | 设置 `debug_mode = True` |

# 附录：状态机代码架构说明

## 架构概览

代码使用**全局状态变量** `state_id` 控制，分为两部分：

```
┌────────────────────────────────────────────────────────┐
│                     全局变量 state_id                   │
└────────────────────────────────────────────────────────┘
         │                              │
         ▼                              ▼
┌────────────────────┐        ┌──────────────────────┐
│  image_callback()  │        │   main() 主循环      │
│  (视觉检测部分)     │        │   (运动控制部分)     │
├────────────────────┤        ├──────────────────────┤
│ 根据 state_id 调用 │        │ 根据 state_id 发送   │
│ _detect_xxx()      │        │ 运动指令 + 切换状态  │
└────────────────────┘        └──────────────────────┘
         │                              │
         ▼                              ▼
  设置 _X_detected              更新 state_id
  检测标志为True
```

## 代码结构

### 1. 状态定义（文件开头）
```python
state_id = 0  # 全局变量，控制当前状态
```

### 2. 视觉检测部分（image_callback函数）
```python
def image_callback(self, msg):
    current_state = state_id
    if current_state == 0:
        self._detect_0(cv_image)      # 黄色线检测
    elif current_state == 3:
        self._detect_3(cv_image)      # 红色柱检测
    elif current_state == 4:
        self._detect_4(cv_image)
    # ... 更多状态
```

### 3. 运动控制部分（main主循环）
```python
while rclpy.ok():
    if state_id == 0:
        # 发送前进指令
        if vision_node._0_detected:
            state_id = 1  # 状态切换
    elif state_id == 1:
        # 发送转弯指令
        state_id = 2
    # ... 更多状态
```

## 添加新状态步骤

假设添加状态99（检测圆形并绕行）：

**步骤1**：在 `VisionNode` 类中添加检测函数
```python
def _detect_99(self, cv_image):
    # 检测圆形的逻辑
    if 检测到圆形:
        self._99_detected = True
```

**步骤2**：在 `image_callback` 中注册
```python
elif current_state == 99:
    self._detect_99(cv_image)
```

**步骤3**：在 `main()` 中添加控制逻辑
```python
elif state_id == 99:
    if current_time - last_cmd_time > cmd_interval:
        # 发送绕行指令
        Ctrl.Send_cmd(msg)
        last_cmd_time = current_time

    if vision_node._99_detected:
        state_id = 100  # 跳转到下一状态
```

## 数据流向

```
相机图像 → image_callback → _detect_xxx() → 设置 _X_detected
                                            ↓
                         main循环检查 → 发送运动指令 → 更新 state_id
                                            ↑
                         └─────────────────┘
                              状态闭环
```

## 关键要点

| 要点 | 说明 |
|------|------|
| 状态编号 | 使用整数（0,1,2...）或小数（4.5, 18.5） |
| 检测函数 | 命名格式 `_detect_状态号()` |
| 检测标志 | 命名格式 `_状态号_detected`，存储在 `vision_node` |
| 状态切换 | 在 `main()` 中修改 `state_id` 值 |
| 通信方式 | 通过全局变量和类成员变量共享状态 |
