报错mkstemp: No such file or directory   . 原因：首次进入时狗端 root 用户的 /root/.ssh/ 目录可能还不存在，所以这句失败：
```
sudo ssh-keygen -f "/root/.ssh/known_hosts" -R "192.168.44.233"
```
  先创建目录和空文件，再执行原流程：
```
cd /home/mi/cyberdog_locomotion/scripts/

sudo mkdir -p /root/.ssh
sudo chmod 700 /root/.ssh
sudo touch /root/.ssh/known_hosts
sudo chmod 600 /root/.ssh/known_hosts

sudo ssh-keygen -f "/root/.ssh/known_hosts" -R "192.168.44.233"

sudo ./scp_to_cyberdog.sh

ssh root@192.168.44.233 'chmod -R +x /robot/robot-software/ && export
LD_LIBRARY_PATH=/robot/robot-software/build; /robot/robot-software/manager /
robot/ > /robot/manager.log 2>&1 & sleep 1; ps | grep -E "manager|
cyberdog_control" | grep -v grep'
```
  如果后面 ssh root@192.168.44.233 又提示 host key 确认，输入 yes。如果提示密
  码，通常是 root 侧密码或脚本里预设的登录方式问题，那个就要再看新的报错。
