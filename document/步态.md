# 1

我读了 `document/24年文档.pdf`，更改步态的方法集中在 **10.3 运控文档(重要)**，主要是通过设置 `msg.mode` + `msg.gait_id` 来切换步态（文档页约 44–53）。

**最快更改步态（已有步态）**  
在 LCM 控制里切换 `gait_id` 即可。文档示例在 locomotion 模式下这样用：

```python
msg.mode = 11  # Locomotion
msg.gait_id = 27  # 例：TROT_SLOW
msg.vel_des = [0, 0, 0.5]
msg.step_height = [0.06, 0.06]
msg.duration = 0
msg.life_count += 1
Ctrl.Send_cmd(msg)
```

文档还给了 `control_flags_release.hpp` 中 `GAIT_ID` 列表，`motion=11` 下的 `gait_id` 对应各种步态（例如 `27=trot slow`, `26=trot 24-16`, `3=trot user` 等）。  
对应文件路径（文档注明）：
- `cyberdog_locomotion/common/include/control_flags_release.hpp`

**自定义步态（更改/新增）**  
文档给出两种方式：

1. **直接自定义步态**  
- 自定义步态的 `gait_id` 统一为 `110`。  
- 需要写两个文件：  
  - 状态定义：`user_gait_XX.toml`  
  - 步态参数：`cyberdog2_userXX_*.toml`  
- 再通过 `msg.mode = x` / `msg.gait_id = y` 调用。

2. **把自定义步态打包成 mode+gait_id**  
文档示例：
```python
msg.mode = 62
msg.gait_id = 92  # up10cmstair
msg.life_count += 1
msg.duration = 0
Ctrl.Send_cmd(msg)
```
映射关系在：
- `cyberdog_locomotion/common/src/command_interface/command_interface.cpp`

**常用参数位置**  
如果要调整抬腿高度等参数，文档指出：
- `cyberdog_locomotion/common/config/cyberdog2-ctrl-user-parameters.yaml`
- `step_height_max` 会影响高抬腿/上台阶能力
